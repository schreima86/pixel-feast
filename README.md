# Pixel Feast

Color-Sort-Puzzle: Ameisen fressen Pixelbilder farbweise leer. Single-File-HTML (vanilla JS), installierbar als PWA.

Spielen: https://schreima86.github.io/pixel-feast/

iOS/Android: in Safari/Chrome öffnen → Teilen → „Zum Home-Bildschirm“.

Eigener Code, eigene Pixelgrafiken. Lizenz: MIT.
